# Backend placeholder — M1

This folder exists as required by Milestone 1. No API is implemented yet.

- `dao/`: M2 PDO DAO classes
- `services/`, `routes/`: M3 FlightPHP business logic, REST routes and Spoonacular API integration
- `middleware/`: M4 JWT verification, roles, request logging and exception handling
- `config/config.example.php`: safe template; copy to Git-ignored `config.php` during backend development
- `logs/`: runtime info and error logs, ignored by Git

The frontend remains pure HTML/CSS/JS and is served separately.
